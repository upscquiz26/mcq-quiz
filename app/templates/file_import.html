Everything is saved as needs review. There is no original page to compare with (except for pictures, which are read like a scanned paper), so check the questions against your own source. First you get a report; nothing is saved until you say so.

Which file?

  • Spreadsheet (.csv, .xlsx) — one question per row. You say which column is which (the app guesses from the headers and remembers your choice for the next file with the same headers). Answers must be the letters A–D.
  • Word document (.docx) — numbered questions typed as text (1., 2. …) with options (a)–(d), and optionally an Answer: (b) line under each question or an answer key at the end. Word's automatic numbering isn't stored in the text, so type the numbers.
  • Pictures (.png, .jpg …) — photos or screenshots of the pages, in page order. They are read by OCR like a scanned paper, so Tesseract must be installed.
Adding to a paper only fills question numbers it doesn't have yet; existing questions are never overwritten.
Several files only for pictures (they become pages 1, 2, 3 … in the order you choose them, usually alphabetical).
