Use this when another AI has read a paper for you and produced JSON. That JSON isn't trusted: every question is saved as needs review, labelled “AI-supplied, unverified”, and can't reach a student until you have checked and confirmed it. First you get a report (nothing is saved); then you decide whether to import.

1. Get the JSON from an AI

  1. Click Copy prompt and paste it into the other AI, then attach the question paper PDF.
  2. It should convert the whole paper. If a reply is too long for it to finish, it stops after a complete question and you say “next” for the rest.
  3. Save each reply as a .json file, or paste it below. A closing line such as “Covered questions 1 to 25.” is fine.

Download prompt Download template

Show the prompt
If the button doesn't work, click in the box, press Ctrl+A then Ctrl+C.

2. Check it (nothing is saved yet)

Adding to a paper skips question numbers it already has. Only questions still waiting for review can be replaced, and only if you ask.
If you give it, each question's page number lets the review screen show that original page beside it (for you only, never for students).

There is no limit on the number of parts, questions or file size. A backup of the database is made automatically before every import. Topics in the JSON are only used if they already exist under that subject; subjects outside the fixed list are left blank.
